容器是STL的核心组成部分，用于存储和管理数据。GESP考试中常用容器按考察级别从低到高排列如下。

2.1 string 字符串容器 2级入门 · 3级进阶

📋 基本信息

头文件：#include <string>

功能说明：C++标准字符串类，替代C语言char数组，支持动态扩容、丰富的字符串操作函数。

核心函数

  • s.size() / s.length() 获取字符串长度，返回字符个数
  • s.empty() 判断是否为空，返回bool值
  • s[i] 下标访问第i个字符（从0开始）
  • s1 + s2 字符串拼接，返回新字符串
  • s += "abc" 追加字符串/字符
  • s.substr(pos, len) 从pos位置截取len个字符的子串
  • s.find(str) 查找子串，返回起始下标；找不到返回string::npos
  • s.erase(pos, len) 从pos位置删除len个字符
  • s.insert(pos, str) 在pos位置插入字符串
  • getline(cin, s) 读取一整行字符串（含空格）

代码样例

#include <iostream> #include <string> using namespace std; int main() { // 1. 初始化 string s = "Hello GESP"; // 2. 基本操作 cout << s.size() << endl; // 输出：9 cout << s[0] << endl; // 输出：H // 3. 拼接 s += "!"; cout << s << endl; // 输出：Hello GESP! // 4. 截取子串 cout << s.substr(6, 4) << endl; // 输出：GESP // 5. 查找 if (s.find("GESP") != string::npos) { cout << "找到GESP" << endl; } return 0; }

GESP常见考点

字符串反转（配合reverse函数）
回文字符串判断
统计字符出现次数
字符串与数字相互转换

2.2 vector 动态数组 3级入门 · 4级核心

📋 基本信息

头文件：#include <vector>

功能说明：动态数组，自动管理内存，可随时改变大小，支持随机访问，是GESP最常用的容器。

核心函数

  • vector<int> v 声明一个int类型的空vector
  • vector<int> v(n) 声明n个元素，默认初始化为0
  • vector<int> v(n, val) 声明n个元素，初始值都是val
  • v.push_back(x) 在末尾添加元素x
  • v.pop_back() 删除最后一个元素（无返回值）
  • v.size() 获取元素个数
  • v.empty() 判断是否为空
  • v[i] 下标访问第i个元素
  • v.front() / v.back() 获取第一个/最后一个元素
  • v.clear() 清空所有元素
  • v.insert(pos, x) 在迭代器pos位置前插入元素x，如v.insert(v.begin()+1, 99)
  • v.insert(pos, cnt, x) 在pos位置前连续插入cnt个x
  • v.erase(pos) 删除pos位置的一个元素，返回删除后下一个位置的迭代器
  • v.erase(first, last) 删除区间[first, last)内的元素，常用于配合unique去重
  • v.resize(n, val) 调整元素个数为n，变大时新元素填val（省略val则默认初始化）
  • v.reserve(n) / v.capacity() 预留容量 / 查看当前容量；reserve不改变size
  • v.begin() / v.end() 首元素迭代器 / 尾后迭代器，常用于sort、遍历、insert、erase

代码样例

#include <iostream> #include <vector> using namespace std; int main() { // 1. 初始化 vector<int> v; // 2. 添加元素 v.push_back(10); v.push_back(20); v.push_back(30); // 3. 访问元素 cout << v[0] << endl; // 10 cout << v.size() << endl; // 3 // 4. 遍历 for (int i = 0; i < v.size(); i++) { cout << v[i] << " "; } // 5. 删除末尾 v.pop_back(); // 6. insert：在下标1前插入99，结果 10 99 20 v.insert(v.begin() + 1, 99); // 7. erase：删除下标1的元素，结果 10 20 v.erase(v.begin() + 1); // 8. resize / reserve v.resize(5, 0); // size变为5，新元素补0 v.reserve(100); // 预留容量，不改变size return 0; }

GESP常见考点

vector存储数据，配合sort排序
vector作为函数参数（传引用）
二维vector：vector<vector<int>>
迭代器遍历（4级以上）
insert/erase会移动后续元素，时间复杂度通常为O(n)
reserve只扩容量不改元素个数，resize会改变size

2.3 stack 栈 5级原理 · 6级STL

📋 基本信息

头文件：#include <stack>

功能说明：后进先出（LIFO）的线性数据结构，只能在栈顶操作。

核心函数

  • stack<int> st 声明一个int类型的栈
  • st.push(x) 元素x入栈（压到栈顶）
  • st.pop() 弹出栈顶元素（无返回值！）
  • st.top() 获取栈顶元素（不删除）
  • st.empty() 判断栈是否为空
  • st.size() 获取栈中元素个数
⚠️ 易错点
pop()无返回值！不能写 int x = st.pop();，应该先 top() 取值再 pop() 删除。

代码样例

#include <iostream> #include <stack> using namespace std; int main() { stack<int> st; // 入栈 st.push(10); st.push(20); st.push(30); cout << st.size() << endl; // 3 cout << st.top() << endl; // 30（栈顶） // 出栈（先取值再删除） int x = st.top(); st.pop(); cout << x << endl; // 30 cout << st.top() << endl; // 20 return 0; }

GESP常见考点

括号匹配问题
表达式求值（后缀表达式）
十进制转二进制
栈的数组模拟实现（5级）

2.4 queue 队列 5级原理 · 6级STL

📋 基本信息

头文件：#include <queue>

功能说明：先进先出（FIFO）的线性数据结构，队尾入队，队头出队。

核心函数

  • queue<int> q 声明一个int类型的队列
  • q.push(x) 元素x入队（加到队尾）
  • q.pop() 弹出队头元素（无返回值）
  • q.front() 获取队头元素
  • q.back() 获取队尾元素
  • q.empty() 判断队列是否为空
  • q.size() 获取队列元素个数

代码样例

#include <iostream> #include <queue> using namespace std; int main() { queue<int> q; // 入队 q.push(10); q.push(20); q.push(30); cout << q.front() << endl; // 10（队头） cout << q.back() << endl; // 30（队尾） // 出队 q.pop(); cout << q.front() << endl; // 20 return 0; }

GESP常见考点

BFS广度优先搜索
队列的数组模拟实现
约瑟夫环问题
层次遍历（树/图）

📋 基本信息

头文件：#include <deque>

功能说明：双端队列，两端都可以高效地插入和删除元素，支持随机访问。

核心函数

  • dq.push_front(x) 在队头添加元素
  • dq.push_back(x) 在队尾添加元素
  • dq.pop_front() 删除队头元素

2.6 list 链表 8级拓展

📋 基本信息

头文件：#include <list>

功能说明：双向链表，适合频繁在中间插入和删除元素；不支持下标随机访问，不能使用lst[i]。

核心函数

  • list<int> lst 声明一个int类型链表
  • lst.push_back(x) / lst.push_front(x) 尾部 / 头部插入元素x
  • lst.pop_back() / lst.pop_front() 删除尾部 / 头部元素
  • lst.insert(pos, x) 在迭代器pos前插入x
  • lst.erase(pos) 删除pos位置元素，返回下一个位置
  • lst.remove(x) 删除所有等于x的元素
  • lst.sort() / lst.reverse() 链表内部排序 / 反转；list不能直接用algorithm里的sort

代码样例

#include <iostream> #include <list> using namespace std; int main() { list<int> lst = {3, 1, 2}; lst.push_front(0); lst.push_back(4); list<int>::iterator it = lst.begin(); ++it; // 指向第二个位置 lst.insert(it, 99); // 在it前插入 lst.remove(99); // 删除所有99 lst.sort(); // list专用排序 for (int x : lst) cout << x << " "; return 0; }

GESP常见考点

理解链表不支持随机访问，不能写lst[i]
中间插入/删除依赖迭代器
list排序使用lst.sort()，不是sort(lst.begin(), lst.end())

2.7 priority_queue 优先级队列 7级

📋 基本信息

头文件：#include <queue>

功能说明：堆实现的优先级队列，队首元素始终是优先级最高（最大/最小）的元素。

核心函数

  • priority_queue<int> pq 大顶堆（默认，最大元素在队首）
  • priority_queue<int, vector<int>, greater<int>> 小顶堆（最小元素在队首）
  • pq.push(x) 插入元素
  • pq.pop() 删除队首元素
  • pq.top() 获取队首元素

代码样例

#include <iostream> #include <queue> using namespace std; int main() { // 大顶堆（默认） priority_queue<int> maxHeap; maxHeap.push(3); maxHeap.push(1); maxHeap.push(2); cout << maxHeap.top() << endl; // 3 // 小顶堆 priority_queue<int, vector<int>, greater<int>> minHeap; minHeap.push(3); minHeap.push(1); minHeap.push(2); cout << minHeap.top() << endl; // 1 return 0; }

GESP常见考点

Dijkstra最短路算法
TopK问题（前K大/小元素）
哈夫曼树

2.8 set / multiset 集合 7级

📋 基本信息

头文件：#include <set>

功能说明：底层红黑树实现，元素自动排序且不重复（set）；multiset允许重复元素。

核心函数

  • s.insert(x) 插入元素x
  • s.erase(x) 删除值为x的元素
  • s.find(x) 查找x，返回迭代器；找不到返回s.end()
  • s.count(x) 统计x的个数（set中0或1）
  • s.size() 元素个数
  • s.lower_bound(x) 第一个 ≥ x 的迭代器
  • s.upper_bound(x) 第一个 > x 的迭代器

代码样例

#include <iostream> #include <set> using namespace std; int main() { set<int> s; s.insert(3); s.insert(1); s.insert(2); s.insert(2); // 重复，不插入 cout << s.size() << endl; // 3 // 遍历（自动升序输出 1 2 3） set<int>::iterator it; for (it = s.begin(); it != s.end(); it++) { cout << *it << " "; } // 查找 if (s.find(2) != s.end()) { cout << "找到2" << endl; } return 0; }

2.9 map / multimap 映射 7级

📋 基本信息

头文件：#include <map>

功能说明：键值对存储（key-value），key自动排序且唯一，底层红黑树。

核心函数

  • m[key] = value 插入或修改键值对
  • m.insert(pair) 插入键值对
  • m.erase(key) 删除指定key的元素
  • m.find(key) 查找key，返回迭代器
  • m.count(key) 统计key出现次数
  • m.size() 键值对个数
⚠️ 易错点
用 [] 访问不存在的key时，会自动插入一个默认值！判断是否存在请用 find() 或 count()。

代码样例

#include <iostream> #include <map> #include <string> using namespace std; int main() { map<string, int> m; // 插入 m["apple"] = 5; m["banana"] = 3; // 修改 m["apple"]++; // 变成6 // 遍历（按key字典序） map<string, int>::iterator it; for (it = m.begin(); it != m.end(); it++) { cout << it->first << ": " << it->second << endl; } // 安全查找 if (m.count("orange") > 0) { cout << m["orange"] << endl; } return 0; }

GESP常见考点

统计单词/字符出现频率
字典序排序输出
键值对映射关系

2.10 unordered 哈希容器 8级拓展

set / map（红黑树）

  • 有序存储
  • 插入/查找/删除：O(log n)
  • 支持lower_bound等有序操作
  • GESP 7级要求

unordered_set / unordered_map（哈希表）

  • 无序存储
  • 插入/查找/删除：O(1) 平均
  • 速度更快
  • GESP 8级拓展

代码样例

#include <iostream> #include <unordered_set> #include <unordered_map> using namespace std; int main() { // 无序集合 unordered_set<int> us; us.insert(3); us.insert(1); cout << us.count(1) << endl; // 1 // 无序映射 unordered_map<string, int> um; um["hello"] = 10; return 0; }

STL提供了丰富的算法函数，头文件 #include <algorithm>。

3.1 排序算法 4级基础 · 7级进阶

📋 基本信息

头文件：#include <algorithm>

时间复杂度：O(n log n)

稳定性：不稳定排序

核心函数

  • sort(begin, end) 默认升序排序
  • sort(begin, end, greater<int>()) 降序排序
  • sort(begin, end, cmp) 自定义比较函数排序
  • stable_sort() 稳定排序（相等元素保持原顺序）

代码样例

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> v = {3, 1, 4, 2}; // 升序（默认） sort(v.begin(), v.end()); // 结果：1 2 3 4 // 降序 sort(v.begin(), v.end(), greater<int>()); // 结果：4 3 2 1 // 普通数组 int a[] = {3, 1, 2}; sort(a, a + 3); return 0; }

3.2 二分查找算法 6级binary_search · 7级上下界

⚠️ 重要前提

二分查找的数组必须是有序的（默认升序），否则结果错误！

核心函数

  • binary_search(b, e, x) 判断x是否存在，返回bool（6级）
  • lower_bound(b, e, x) 第一个 ≥ x 的迭代器（7级）
  • upper_bound(b, e, x) 第一个 > x 的迭代器（7级）
  • equal_range(b, e, x) 返回x的区间[lower, upper)

代码样例

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> v = {1, 2, 3, 7, 7, 7}; // 1. 判断是否存在 if (binary_search(v.begin(), v.end(), 7)) { cout << "存在7" << endl; } // 2. lower_bound：第一个 >= 7 vector<int>::iterator low = lower_bound(v.begin(), v.end(), 7); cout << low - v.begin() << endl; // 下标3 // 3. upper_bound：第一个 > 7 vector<int>::iterator up = upper_bound(v.begin(), v.end(), 7); cout << up - v.begin() << endl; // 下标6 // 4. 统计7的个数 cout << up - low << endl; // 3个 return 0; }

GESP常见考点

判断元素是否存在
统计元素出现次数
求第一个大于/小于的位置
降序数组需加greater比较器

3.3 最值与统计算法

核心函数

  • max(a, b) / min(a, b) 两个数的最大/最小值
  • max_element(b, e) 区间最大值迭代器，加*取值
  • min_element(b, e) 区间最小值迭代器
  • count(b, e, val) 统计等于val的元素个数
  • count_if(b, e, 条件) 按条件统计

代码样例

vector<int> v = {3, 1, 4, 2, 3}; // 最大值 cout << *max_element(v.begin(), v.end()) << endl; // 4 // 最小值 cout << *min_element(v.begin(), v.end()) << endl; // 1 // 统计3的个数 cout << count(v.begin(), v.end(), 3) << endl; // 2

3.4 修改操作算法 4~6级

核心函数

  • reverse(b, e) 反转区间元素
  • fill(b, e, val) 将区间填充为val
  • swap(a, b) 交换两个变量
  • unique(b, e) 去重（相邻重复元素），返回去重后尾迭代器
  • copy(b1, e1, b2) 拷贝区间到另一位置
⭐ 重点：unique去重三步法

注意：unique只能去除相邻重复元素，所以必须先排序！

三步法：sort → unique → erase

代码样例（unique去重）

#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> v = {3, 1, 2, 3, 1, 2, 2}; // 第1步：排序 sort(v.begin(), v.end()); // 第2步：去重（返回去重后的尾位置） vector<int>::iterator ed = unique(v.begin(), v.end()); // 第3步：删除多余元素 v.erase(ed, v.end()); // 结果：1 2 3 return 0; }

GESP常见考点

字符串反转
数组去重（unique三步法）
数组初始化填充
交换两个变量

3.5 查找与判断算法 4~7级

核心函数

  • find(b, e, x) 在线性区间[b, e)中查找x，返回迭代器；找不到返回e
  • find_if(b, e, 条件) 查找第一个满足条件的元素
  • all_of(b, e, 条件) 判断是否所有元素都满足条件
  • any_of(b, e, 条件) 判断是否至少一个元素满足条件
  • none_of(b, e, 条件) 判断是否没有元素满足条件

代码样例

vector<int> v = {2, 4, 6, 9}; if (find(v.begin(), v.end(), 6) != v.end()) { cout << "找到6" << endl; } bool allEven = all_of(v.begin(), v.end(), [](int x) { return x % 2 == 0; }); bool hasOdd = any_of(v.begin(), v.end(), [](int x) { return x % 2 == 1; });

GESP常见考点

find是线性查找，区间不需要有序
binary_search/lower_bound要求区间已排序
判断返回值时要和end()比较

3.6 排列与数值算法 6~8级

核心函数

  • next_permutation(b, e) 生成下一个字典序排列；存在则返回true，否则返回false并变回最小排列
  • prev_permutation(b, e) 生成上一个字典序排列
  • accumulate(b, e, init) 区间求和/累积，头文件#include <numeric>
  • partial_sum(b, e, out) 前缀和写入out位置，常用于构造前缀和数组

代码样例

#include <algorithm> #include <numeric> vector<int> a = {1, 2, 3}; do { for (int x : a) cout << x; cout << endl; } while (next_permutation(a.begin(), a.end())); vector<int> b = {1, 2, 3, 4}; int sum = accumulate(b.begin(), b.end(), 0); // 10 vector<int> prefix(b.size()); partial_sum(b.begin(), b.end(), prefix.begin()); // 1 3 6 10

GESP常见考点

枚举全排列前先sort，确保从最小字典序开始
accumulate第三个参数决定结果类型，long long求和写0LL
partial_sum适合快速构造一维前缀和

⚠️ 第六部分 常见易错点与避坑指南

6.1 容器类易错点

❌ vector 越界访问
vector 的 [] 运算符不检查越界，访问 v[v.size()] 会导致运行时错误。一定要确保下标在 0 ~ size()-1 范围内。
❌ stack/queue 空时调用 top/pop
空栈调用 top() 或 pop() 会崩溃！使用前一定要判断 empty()。
❌ map [] 自动插入
用 [] 访问不存在的 key 时，会自动插入一个默认值（如0）。判断是否存在请用 find() 或 count()。
❌ pop() 无返回值
stack 和 queue 的 pop() 只删除不返回值！正确写法：先 top()/front() 取值，再 pop() 删除。

6.2 算法类易错点

❌ 二分查找前数组无序
binary_search、lower_bound 等函数要求数组必须有序！使用前一定要先 sort。
❌ unique 去重前不排序
unique 只能去除相邻重复元素，不排序直接用去重不彻底。正确三步法：sort → unique → erase。
❌ lower_bound 返回 end() 不判断
找不到时返回 end() 迭代器，直接解引用 *it 会崩溃。使用前务必判断 it != v.end()。

6.3 输入输出易错点

❌ cin 太慢导致超时
大数据量时 cin 可能超时。加上两行加速： ios::sync_with_stdio(false); cin.tie(0);
❌ long long 用 %d 输出
long long 类型必须用 %lld 格式化输出，用 %d 会输出错误结果。

6.4 迭代器易错点

❌ erase 后迭代器失效
vector 删除元素后，指向被删位置及之后的迭代器全部失效。正确写法：it = v.erase(it);
❌ 用 < 比较迭代器
不是所有容器都支持 < 比较迭代器（如list）。统一用 != 来判断是否到 end() 更安全。
