指针基础：考试范围不止一行 *

把指针当作“存放地址的变量”：声明时的 * 说明类型，表达式里的 * 才是沿地址取值。判断题和填空题最爱在这两个位置换概念。

四级范围：指针的定义、赋值与解引用；值传递 / 引用传递 / 指针传递；结构体指针。更高等级会在数组、字符串、函数和数据结构题中持续使用这些基础。
  1. 声明 int *p;：p 指向 int，不是“p 和 *p 都是 int”。
  2. 取地址 p = &a;：将变量 a 的地址交给 p。
  3. 解引用 *p：访问 p 指向的对象；写入会改到原变量。
  4. 传参 需要改实参时，用引用或指针；只读计算通常用值传递更直观。
  5. 结构体 node->next 等价于 (*node).next。

把指针拆成 6 个高频考点

1

定义：int *p;

int *p;

p 是指向 int 的指针，里面存放的是地址。

2

取地址：p = &a;

int a = 10; p = &a;

&a 表示变量 a 的地址，交给 p 保存。

3

解引用：cout << *p;

cout << *p;

*p 是 p 指向的对象，也就是 a 的值。

4

修改：*p = 20;

*p = 20;

通过指针修改所指对象，此时 a 的值也变为 20。

5

空指针：nullptr

int *p = nullptr;

表示未指向有效对象；可以判断，不能解引用。

6

指针传参

void swap(int *x, int *y)

传入地址，函数内修改 *x、*y 会影响实参。

考场最容易错的地方

1

声明时，星号只属于一个变量

int* p, q;
p = &a; q = &a; // 错
int *p, *q;
p = &a; q = &a;
2

p 是地址，*p 才是值

cout << p; // 地址
cout << *p; // a 的值
3

nullptr 不能解引用

int *p=nullptr;
cout << *p; // 错
if (p != nullptr) {
 cout << *p; }
4

指针类型必须匹配

int a=0;
double *p=&a; // 错
int *p = &a;
// 类型一致
5

局部变量地址不能越过生命周期

int* f(){ int a=10;
 return &a; // 错 }
不要返回局部变量地址；
改为返回值或有效对象。
6

二维数组不是 int**

int a[3][4];
int **p = a; // 错
int (*p)[4] = a;
// 保留列数

传参与数组：先问“谁会被改动”

方式形参示例函数内改形参考试判断
值传递void f(int x)不会影响实参得到的是副本。
引用传递void f(int &x)会影响实参x 是实参的别名，调用时写 f(a)。
指针传递void f(int *p)改 *p 会影响实参调用写 f(&a)；p 本身仍是地址副本。
二维数组提醒：int a[2][3]; 的 a+1 跳过一整行（3 个 int）。因此能接收它的是“指向含 3 个 int 的数组的指针” int (*p)[3]，不是 int**。

考场收笔前 20 秒

  • 指针是否已初始化，且没有对 nullptr 解引用？
  • * 当前是声明符，还是“取所指对象”的运算符？
  • 函数究竟改的是副本、别名，还是 *p 指向的实参？
  • 数组下标有没有越界？二维数组的列数与指针类型是否一致？
  • 地址所指对象是否还在生命周期内，类型是否匹配？
