先把树的语言说清楚

做题时先圈出根、父子、叶子、层数，再判断题目说的是普通二叉树、完全二叉树，还是二叉搜索树。

1

根、父、子、兄弟

最上方是根。一个结点直接连出的下一层是孩子；拥有同一个父结点的结点互为兄弟。根没有父结点。

2

度与叶子

结点的度是孩子数量。二叉树中度只能是 0、1、2；度为 0 的结点就是叶子结点。

3

深度与高度

本页约定根深度为 1，空树高度为 0。结点深度从根往下数；树高是最深结点的深度。

4

子树与递归

每个结点的左、右孩子又各自带着一棵二叉树。这个“结构重复”正是递归模板能工作的原因。

5

满二叉树

常见考级语境中，每一层都放满：高度为 h 时结点数恰为 2h-1。注意不同教材术语可能略有差别。

6

完全二叉树

除最后一层外都放满，最后一层从左到右连续。最适合用数组紧凑存储，不能在中间随意挖空。

7

二叉搜索树 BST

无重复值时，左子树所有值小于根，右子树所有值大于根，并且左右子树也要满足同样规则。

8

平衡不是完全

平衡关注左右子树高度差；完全关注结点是否按层从左连续摆放。两个概念不能互相替代。

第 k 层至多 2k-1根所在第 1 层最多 1 个结点。
高度 h 至多 2h-1每层都放满时达到最大值。
n0 = n2 + 1任意非空二叉树：叶子数 = 度为 2 的结点数 + 1。
边数 = n - 1含 n 个结点的树恰有 n-1 条父子边。

前序遍历

口诀：根 → 左 → 右

先记录当前根，再递归访问左子树和右子树。

点击“播放”或“下一步”，观察访问顺序。

考场心法：把 visit/输出语句圈出来。它在两个递归调用之前是前序，中间是中序，之后是后序。

struct Node {
    int val;
    Node* left;
    Node* right;

    Node(int x)

};

易错：创建新结点时要初始化左右指针。递归函数第一行通常先处理 root == nullptr。

由遍历序列还原一棵树

中序负责切开左右子树；前序第一个或后序最后一个负责告诉你当前根是谁。

1. 在前序中找根

前序 A B D E C F G 的第一个 A 就是整棵树的根。

2. 用根切中序

中序 D B E | A | F C G：A 左侧都是左子树，右侧都是右子树。

3. 分别递归

左子树前序从 B 开始，右子树前序从 C 开始；每次重复“找根 + 切中序”。

4. 写出目标序列

若问后序，就等左右子树都完成后再写根：D E B F G C A。

六套考场代码模板

先看函数负责哪一棵子树，再看空指针出口，最后检查输出语句相对两个递归调用的位置。

递归遍历

只移动一行 cout，就能切换前、中、后序。

前序放最前；中序放两次递归中间；后序放最后。
void dfs(Node* root) {
    if (root == nullptr) return;

    cout << root->val << ' '; // 前序
    dfs(root->left);
    // cout << root->val << ' '; // 中序
    dfs(root->right);
    // cout << root->val << ' '; // 后序
}

队列做层序遍历

队列保证先入先出，因此同一层天然从左到右。

若要按层换行，要先保存本层数量 q.size()。
void levelOrder(Node* root) {
    if (root == nullptr) return;
    queue<Node*> q;
    q.push(root);
    while (!q.empty()) {
        int levelSize = q.size();
        while (levelSize--) {
            Node* cur = q.front(); q.pop();
            cout << cur->val << ' ';
            if (cur->left) q.push(cur->left);
            if (cur->right) q.push(cur->right);
        }
        cout << '\n';
    }
}

高度与结点计数

高度取左右最大值；结点总数把左右数量相加。

不要把 max 与加法混淆。
int height(Node* root) {
    if (root == nullptr) return 0;
    return max(height(root->left),
               height(root->right)) + 1;
}

int countNodes(Node* root) {
    if (root == nullptr) return 0;
    return countNodes(root->left)
         + countNodes(root->right) + 1;
}

栈实现非递归前序

栈后进先出。想先访问左孩子，就必须先把右孩子压栈。

口诀：输出当前；右先入栈，左后入栈。
void preorderStack(Node* root) {
    if (root == nullptr) return;
    stack<Node*> st;
    st.push(root);
    while (!st.empty()) {
        Node* cur = st.top(); st.pop();
        cout << cur->val << ' ';
        if (cur->right) st.push(cur->right);
        if (cur->left) st.push(cur->left);
    }
}

BST 递归插入

每次只走左或右一条路径，并把递归返回的新子树接回原位置。

最常漏写的是 root->left = ... 和最后的 return root。
Node* insert(Node* root, int x) {
    if (root == nullptr) return new Node(x);
    if (x < root->val)
        root->left = insert(root->left, x);
    else if (x > root->val)
        root->right = insert(root->right, x);
    return root;
}

BST 迭代查找

比当前值小向左，大则向右；相等时结束。

复杂度是 O(h)：平衡时约 O(log n)，退化成链时最坏 O(n)。
Node* find(Node* root, int x) {
    while (root != nullptr) {
        if (x == root->val) return root;
        if (x < root->val)
            root = root->left;
        else
            root = root->right;
    }
    return nullptr;
}

二叉搜索树：每次排除一边

BST 的关键不是“左右孩子”两个值，而是整棵左子树都小、整棵右子树都大。

查找 62 的路线

示例 BST 中，从根 50 开始比较：

5062 > 50 →7062 < 70 →6062 > 60 →62

BST 的中序遍历一定按非递减顺序输出；若题目保证值互不相同，就是严格递增。

复杂度看树高 h

较平衡：O(log n)每次比较大约排除一半范围。
退化成链：O(n)依次插入 1,2,3,4… 可能一路向右。

遍历仍然要访问每个结点，所以前、中、后、层序遍历的时间复杂度都是 O(n)。

哈夫曼树：总挑最小的两个

它也是六级常见树考点。题目通常考构造过程、带权路径长度 WPL、结点总数和前缀编码性质。

构造口诀：小、小、合

权值为 2、3、4、7 时，每轮从当前集合选最小的两个合并。

2+3→ 5
4+5→ 9
7+9→ 16

每次合并值相加形成新结点，再把新权值放回集合继续选择。

四个必会结论

WPL = Σ(叶子权值 × 路径长度)
也可把每次合并产生的新权值相加：5 + 9 + 16 = 30。
n 个符号 → 2n - 1 个结点
标准哈夫曼树没有度为 1 的结点。
出现越频繁，编码通常越短
目标是让整棵树的 WPL 最小。
哈夫曼编码是前缀编码
任何字符编码都不是另一个字符编码的前缀，因此不需要分隔符也能唯一解码。

考场最容易错的八个细节

先判树的类型、下标起点和深度约定，再动手算遍历；很多错题不是不会递归，而是条件没读完整。

1

把“中序有序”套到普通二叉树

只有 BST 的中序遍历保证有序。

普通二叉树中序必递增
BST 中序才有序
2

前序 + 后序就说唯一

通常不能唯一确定；需要中序参与切分左右子树。

前序 + 后序 → 唯一
前序/后序 + 中序
3

0 下标与 1 下标公式混用

先看根放在 tree[0] 还是 tree[1]。

根为 0：左孩子 2*i
根为 0：左 2*i+1
4

栈里先压左孩子

栈后进先出，先压左会让右孩子先弹出。

push(left); push(right);
push(right); push(left);
5

树高把两边相加

高度只选更深的一边，再加当前层。

leftH + rightH + 1
max(leftH,rightH)+1
6

忘记空指针出口

递归继续访问空孩子会崩溃或无限递归。

直接访问 root->left
if (!root) return;
7

把完全二叉树当成满二叉树

完全二叉树最后一层可以不满，但必须从左连续。

完全 = 每层都满
最后一层可不满
8

只比较 BST 的直接孩子

BST 约束的是整棵左右子树，不只是相邻三个值。

左孩子小、右孩子大即可
整棵左小、整棵右大

六道真题化样题

依据 2023–2026 本地归档中反复出现的考法原创改编，训练的是同一知识点，不照抄完整真题。

样题 1：判断遍历

递归代码依次执行：访问根、递归左子树、递归右子树。它是哪种遍历？

查看答案

前序遍历。判断名字只看根的访问位置，根在最前。

样题 2：序列还原

前序为 A B D E C F，中序为 D B E A F C，后序是什么？

查看答案

D E B F C A。前序首项 A 是根，中序以 A 切成左右两段。

样题 3：数组下标

完全二叉树根在 tree[0]。下标 i 的右孩子在哪里？

查看答案

tree[2*i+2]。若根从 1 开始，右孩子才是 2*i+1。

样题 4：递归填空

空树高度为 0，左右高度为 L、R，当前树高表达式是什么？

查看答案

max(L,R)+1。最长根到叶路径只经过左右其中一边。

样题 5：非递归前序

用栈并希望先访问左子树，当前结点处理后应按什么顺序压入孩子？

查看答案

先右后左。栈后进先出，左孩子后压才能先弹出。

样题 6：BST 性质

对无重复值的 BST 做哪种遍历能得到严格递增序列？复杂度是多少？

查看答案

中序遍历，O(n)。不管是否平衡，完整遍历都要访问 n 个结点。

① 看类型普通 / 完全 / BST？
② 看根位置前、中、后序的根在哪？
③ 看下标从 0 还是从 1 开始？
④ 看出口空指针返回什么？
⑤ 看复杂度遍历 O(n)，查找 O(h)。
