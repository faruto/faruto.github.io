💻 C++ 代码示例
// 冒泡排序 void bubbleSort(int arr[], int n) { for (int i = 0; i < n - 1; i++) { for (int j = 0; j < n - i - 1; j++) { if (arr[j] > arr[j + 1]) { swap(arr[j], arr[j + 1]); } } } }

📖 算法说明

时间复杂度：O(n²)

空间复杂度：O(1)

稳定性：稳定排序

  • 每轮比较相邻元素，大的往后移
  • 每轮结束，最大元素到末尾
  • 共需 n-1 轮完成排序
