二分答案 — 分巧克力问题

通过动画理解「二分答案」的核心思想：答案具有单调性，在可行/不可行的边界上进行二分搜索

题目回顾

输入N 块巧克力（每块 H×W），K 位小朋友

约束每人分到一块正方形巧克力，且大小相同

目标正方形边长尽可能大，求最大边长

样例：N=2，K=10，巧克力为 6×5 和 5×6

💡 为什么可以二分？
若边长为 L 时能切出 ≥K 块，则边长 L-1 一定也能切出 ≥K 块（单调性）。因此「能否切出」具有 单调性，可以二分答案。
对于边长 L，每块 H×W 的巧克力可切出 ⌊H/L⌋ × ⌊W/L⌋ 块。

C++ 完整实现
// 分巧克力 — 二分答案
#include <bits/stdc++.h>
using namespace std;

int N, K;
int H[100005], W[100005];

// check: 边长为 L 时能否切出 >= K 块
bool check(int L) {
    long long cnt = 0;
    for (int i = 0; i < N; i++)
        cnt += (H[i] / L) * (W[i] / L);
    return cnt >= K;
}

int main() {
    cin >> N >> K;
    int maxLen = 0;
    for (int i = 0; i < N; i++) {
        cin >> H[i] >> W[i];
        maxLen = max(maxLen, min(H[i], W[i]));
    }

    // 二分搜索边长的最大值
    int lo = 1, hi = maxLen, ans = 0;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (check(mid)) {
            ans = mid;        // mid 可行，记录答案
            lo = mid + 1;   // 尝试更大的边长
        } else {
            hi = mid - 1;   // mid 不可行，缩小上界
        }
    }
    cout << ans << endl;
    return 0;
}
关键思路总结
① 识别单调性
若 L 可行 → L-1 也可行
答案空间是 可行/不可行 的分界点
② 确定搜索范围
lo=1（最小），hi=min(H,W)的最大值
复杂度 O(N log M)
③ 实现 check 函数
统计所有巧克力能切出多少块
⌊H/L⌋ × ⌊W/L⌋ 取整相乘
④ 更新逻辑
可行 → ans=mid, lo=mid+1
不可行 → hi=mid-1
